# Filmų katalogas

## Projekto tikslas
Sukurti C++ konsolinę programą filmų katalogui valdyti.

## Temos aprašymas
Programa leidžia saugoti, peržiūrėti, redaguoti ir šalinti filmų duomenis.

## Funkcionalumas
- Create – filmo pridėjimas
- Read – filmų peržiūra
- Update – filmo redagavimas
- Delete – filmo ištrynimas
- Filtravimas pagal žanrą
- Filtravimas pagal įvertinimą

## Failai
- main.cpp – programos kodas
- films.txt – duomenų failas
- README.md – projekto aprašymas

## Paleidimas
1. Atsisiųsti projektą
2. Paleisti programą per C++ aplinką (CLion)
3. Naudoti meniu

## Papildomos funkcijos
- Filtravimas pagal žanrą
- Filtravimas pagal minimalų įvertinimą
